# NEU Project Archive (PixelPusher)

## Description
A decentralized, high-fidelity Knowledge Management platform designed specifically for New Era University (Philippines). Built upon Wiig's Knowledge Management Cycle (Building, Holding, Pooling, Applying), this archive serves as a secure vault for showcasing, approving, and discovering student capstone projects.

## Key Features
* **Role-Based Access Control (RBAC):** Distinct, secure dashboards for Students, Faculty, and Admins.
* **Domain Gatekeeper:** Strict OAuth integration ensuring only verified `@neu.edu.ph` accounts gain access.
* **Knowledge Workflow:** Complete lifecycle management from student submission to faculty approval and institutional archiving.
* **High-Performance UI:** Glassmorphic design powered by Tailwind CSS and Framer Motion.

## Tech Stack
* **Frontend:** React 18, Vite, Tailwind CSS, Framer Motion, Lucide React
* **Backend & Auth:** Node.js, Express, Passport.js (Google OAuth), Supabase
* **Database:** Supabase (PostgreSQL)

## Prerequisites
* Node.js (v18 or higher)
* npm or yarn
* Supabase Account & Google Cloud Console credentials

## Installation & Setup
1. Clone the repository: `git clone <repo-url>`
2. Install dependencies: `npm install`
3. Duplicate `.env.example` to `.env` and fill in your Supabase and Google OAuth keys.
4. Run the development server: `npm run dev`
5. Access the app at `http://localhost:3000`
